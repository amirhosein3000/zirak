# FAKE SPEC A — «تریدر هوشمند برای والکس» (product track)

_Rehearsal only. Written by us to practise spec day; not from Wallex._

## Problem
Most Wallex users are retail traders who trade on emotion, don't use stop-losses, and don't understand
why they lose. Wallex's built-in bots (grid, DCA, rebalance) are rule-based and opaque to beginners.

## Required features
1. An assistant that explains the market for a chosen pair **in Persian**, in plain language.
2. Turn a user's idea, written in Persian, into a trading plan the user can review before anything runs.
3. Test the plan on past data and show the result against simply holding.
4. Run the plan in a **simulated** account and explain every decision.
5. **Conversational assistant (required): a multi-turn Persian chat** where the user can ask follow-up
   questions ("why did you sell yesterday?", "what if I used 5 % instead of 10 %?", "how much did fees
   cost me?") and get answers grounded in their own bot's data. *(We have NOT built this.)*
6. Safety: no real money without explicit user confirmation and clear limits.

## Judging criteria
| Criterion | Weight |
|---|---|
| Idea and value for Wallex users | 25 % |
| UX (mobile, Persian, clarity for beginners) | 30 % |
| Use of AI (useful, safe, grounded) | 30 % |
| Technical quality and demo | 15 % |

## Deliverables
Public demo URL working on a phone, source repository, 3-minute demo video, 5-slide pitch.

## Time limit
36 hours from publication to submission; 5-minute live pitch + 3 minutes of questions.
